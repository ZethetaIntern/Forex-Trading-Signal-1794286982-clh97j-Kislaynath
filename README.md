# Forex-Trading-Signal
# Forex Trading Signal – AI-Powered Analytics

An analytical project focused on Forex trading signal generation, technical analysis, risk management, and business intelligence using Python, R, and Microsoft Power BI.

# Project Overview

This project explores how data analytics and quantitative techniques can support Forex market analysis.

# It includes:

# - Forex price data analysis
# - Technical trading signals
# - BUY, SELL, and HOLD signal datasets
# - Monte Carlo scenario analysis
# - Risk and portfolio data analysis
# - Power BI dashboard and DAX measures
# - R Shiny dashboard prototype

# Technologies Used

- Python – Data analysis and quantitative workflows
- R – Statistical analysis and Shiny dashboard
- Microsoft Power BI – Interactive dashboards and reporting
- DAX – Measures and analytical calculations
- Microsoft Excel – Data validation and supporting analysis
- CSV – Structured datasets

# Dashboard

The project includes a Microsoft Power BI dashboard for exploring Forex signals, risk analytics, and strategy-related information.

The R Shiny prototype provides an additional interface for monitoring Forex signals.

## How to Explore

1. Download or clone this repository.
2. Open "Forex_Trading_Signal_AI_Agent.pbix" using Microsoft Power BI Desktop.
3. Review the CSV datasets and DAX queries.
4. Open "app.R" in RStudio to explore the Shiny dashboard prototype. Required R packages must be installed before running it.

## Dataset Scope

The available Forex price dataset focuses on EUR/USD and contains approximately 500 observations. Results should be interpreted within this limited dataset scope.
